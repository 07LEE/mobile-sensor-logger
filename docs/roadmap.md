# Project Roadmap and Planned Features

Development roadmap and planned features for Mobile Sensor Logger.

## Planned Features

- **Landscape UI Mode**: Dynamic sensor orientation calculation for landscape preview and aiming.
- **Manual Focus Distance**: On-device override for the hyperfocal default, the one part of "manual focus and exposure" the PRO panel does not cover — shutter speed and frame rate are already there.
- **Automated Session Cleanup Policies**: Configurable storage retention limits for old sessions.
